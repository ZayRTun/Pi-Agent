Custom footer extension lives at `~/.pi/agent/extensions/custom-footer.ts`. Uses `ctx.ui.setFooter()` to render a two-column status bar. Key APIs: `ctx.getContextUsage()` for live context bar, `ctx.sessionManager.getBranch()` for completed message I/O token totals, `truncateToWidth`/`visibleWidth` from `@earendil-works/pi-tui` for layout, and per-segment theme keys for dynamic color. I/O token counters only update after turn completion (not mid-stream) because they sum completed AssistantMessage entries. <!-- created=2026-07-29, last=2026-07-29 -->
